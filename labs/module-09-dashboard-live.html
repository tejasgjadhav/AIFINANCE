Build a pre-market dashboard

First we look at our daily market dashboard, which refreshes itself every weekday at 8:30 AM. Then you build a smaller version in Python, with news sentiment and a DCF valuation. Finally an AI writes the morning brief and you check every number in it.

A  watch it live  →  B  build your version  →  C  write and check the brief
Free and keyless. The script uses built-in Python only. No API key, no installs, no internet. Run it in Codex, Google Colab or any Python 3.
The numbers are illustrative. The market snapshot and Company X are made up for teaching. Nothing here is advice to buy or sell.

AWatch it live20 minutes

The instructor opens the daily market dashboard and runs its job by hand. This is how it works every weekday:

  1. A schedule starts it. GitHub Actions runs the job every weekday morning, before the 9:15 AM open.
  2. A Python script calls Claude. It sends a fixed prompt template and the current page.
  3. Claude searches and writes. It runs ten or more web searches for the morning numbers and news, and writes the updated page.
  4. A safety check runs. The script checks the new page is complete before it saves it.
  5. The page is published. GitHub Pages puts it live. Nobody has to press a button.
What we would improve. In the live dashboard, Claude finds and works out the numbers. A number an AI found is hard to defend. In your version, Python computes every number, and AI only writes the words.

BBuild your version40 minutes

cd module-09-dashboard
python3 build_dashboard.py
LayerWhat the script doesResult with our snapshot
L1 IngestReads market_snapshot.csv, headlines.txt and dcf_inputs.csv. A blank number stops the run.10 market inputs, 8 headlines
L3 EngineExpected open = GIFT Nifty minus yesterday's Nifty close.Gap-up, +68 points
L3 EngineCurrency, crude and volatility moves, and net institutional flows.VIX 13.60, low. Net flows +730 crore
L3 EngineScores each headline with a simple word list.4 positive, 4 negative
L3 EngineDCF: five years of cash flow growth, a terminal value, less net debt, per share.Company X about ₹439 a share
L5 OutputWrites dashboard.html with tiles, the scored headlines and the valuation.Open it in a browser

Spot the mistake in the news mood. “Crude oil falls as supply concerns ease” is good news for India, because India imports most of its oil. The word list sees “concerns” and calls it negative. That is why banks use a model like FinBERT, and why a person still reads the output.

Then make it fail on purpose. This is what your capstone viva asks for:

python3 build_dashboard.py --break

It blanks the GIFT Nifty input, refuses to write the dashboard, and says which input is missing.

Optional, in Google Colab: real FinBERT

from transformers import pipeline
finbert = pipeline("text-classification", model="ProsusAI/finbert")
finbert("Crude oil falls as supply concerns ease")

Colab downloads the free FinBERT model the first time. Compare its answer with the word list.

CWrite and check the brief30 minutes

  1. Paste the printed prompt into any free AI chat. It asks for a five-sentence pre-market brief that uses only the given numbers and gives no buy or sell advice.
  2. Check every number in the brief against the ENGINE RESULTS. A number that is not there is a mistake, even if it sounds right.
  3. Paste the checked brief into dashboard.html under Morning brief, and swap screens with the next desk.
