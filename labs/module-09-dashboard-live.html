Build a dashboard that updates itself

Four steps. Set up GitHub, add the API key, connect Claude to GitHub, and paste one prompt. After that, the dashboard refreshes itself every weekday at 6:30 AM, before the market opens.

1  GitHub setup  →  2  API key  →  3  connect Claude  →  4  the prompt
Instructor demo. You need two paid things. A Claude plan (Pro or Max) lets Claude write the files. A Claude API key pays for the daily update. They are billed separately.

1GitHub setup10 minutes

  1. Go to github.com, click New repository, name it market-dashboard, choose Public, tick Add a README, and click Create repository.
  2. Open Settings → Actions → General. Under Workflow permissions, choose Read and write permissions and click Save.
  3. Open Settings → Pages. Under Source, choose Deploy from a branch, pick main and / (root), and click Save.

2API key into GitHub5 minutes

  1. Go to console.anthropic.com, open API Keys, and click Create Key. Copy the key. You will not see it again.
  2. In the repository, open Settings → Secrets and variables → Actions and click New repository secret.
  3. Name it exactly ANTHROPIC_API_KEY, paste the key as the value, and click Add secret.
Never paste the key into a file or into the prompt. GitHub keeps the secret hidden and hands it to the routine only when the routine runs.

3Connect Claude to GitHub5 minutes

  1. Go to claude.ai/code and sign in with your Claude account.
  2. Click Connect GitHub and sign in to GitHub when it asks.
  3. GitHub asks you to install the Claude app. Choose Only select repositories, pick market-dashboard, and click Install.
  4. Back in Claude, choose market-dashboard as the repository for a new session.

4Paste the prompt15 minutes

Paste this whole prompt into the session and send it. Claude writes every file, including the routine that runs at 6:30 AM on weekdays.

Build a pre-market dashboard for the Indian stock market in this repository.
It must update itself every weekday morning with GitHub Actions and publish with GitHub Pages.
Create these four files.

1. index.html
   - One self-contained page with inline CSS and no external scripts.
   - Dark theme, readable on a phone.
   - A header with the title "Pre-Market Dashboard" and a "Last updated" date and time in IST.
   - Tiles for: GIFT Nifty, Nifty 50 previous close, Sensex previous close, India VIX,
     USD/INR, Brent crude, US markets overnight (S&P 500, Nasdaq, Dow),
     and FII and DII net flows from the previous session.
   - An "Expected open" tile: GIFT Nifty minus the Nifty previous close, in points,
     labelled gap-up, flat or gap-down.
   - A "Top headlines" section with 8 market headlines. Each one has a source,
     a tone label (positive, negative or neutral) and one line on who it helps or hurts.
   - A "Morning brief" of five plain sentences.
   - A footer that says: "For learning only. Not investment advice. Numbers come from
     web search and can be wrong. Check them before you rely on them."
   - The first version can hold placeholder values.

2. scripts/prompt_template.md
   The instructions the routine sends to Claude each morning:
   - Run at least 10 web searches for today's numbers and news.
   - For every number, give the source and the time it was published.
   - If a number cannot be found, write "not found". Never guess or invent one.
   - Work out the expected open from the two numbers found.
   - Write the morning brief using only numbers that appear on the page.
   - Give no buy, sell or target-price advice, and name no stock as a pick.
   - Return only the complete updated index.html, from <!doctype html> to </html>.

3. scripts/update_dashboard.py
   - Read ANTHROPIC_API_KEY from the environment. Stop with a clear message if it is missing.
   - Use the official anthropic Python SDK and the model claude-sonnet-5-5.
   - Send prompt_template.md plus the current index.html.
   - Turn on the web search tool: {"type": "web_search_20250305", "name": "web_search", "max_uses": 15}.
   - Join the text blocks of the reply into one string.
   - Safety check before saving: the reply must start with <!doctype html>, end with </html>,
     contain the words "Expected open" and "Not investment advice", and be at least 3,000 characters.
   - If the check fails, keep the old index.html, print why, and exit with an error.
   - If it passes, write the new index.html.

4. .github/workflows/daily-update.yml
   - Run on a schedule with cron "0 1 * * 1-5", which is 6:30 AM IST, Monday to Friday.
   - Also allow a manual run with workflow_dispatch.
   - permissions: contents: write.
   - Steps: check out the repository, set up Python 3.12, pip install anthropic,
     run scripts/update_dashboard.py with ANTHROPIC_API_KEY from secrets,
     then commit and push index.html only if it changed.

Also replace README.md with a short note on what the dashboard does and how to run it by hand.
Do not add any personal holdings, portfolio values or my own views on any stock.
When you finish, list the files you created and tell me how to run the workflow once by hand.
  1. When Claude finishes, click Create PR, then open the pull request on GitHub and click Merge. The files are now on main.
  2. Open the Actions tab, click daily-update, then Run workflow, to test it once without waiting for the morning.
  3. When it shows a green tick, open https://YOUR-USERNAME.github.io/market-dashboard/.
If GitHub refuses the workflow file. Some connections are not allowed to add files inside .github/workflows. Then ask Claude to print the file, and on GitHub click Add file → Create new file, name it .github/workflows/daily-update.yml, paste it and commit.
